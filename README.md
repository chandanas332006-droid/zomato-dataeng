# 🍽️ Zomato Data Engineering Pipeline

An end-to-end data engineering pipeline that ingests, transforms, and enriches Zomato restaurant, order, menu, and customer review data — orchestrated with **Apache Airflow**, modeled with **dbt**, warehoused in **Snowflake**, staged on **AWS S3**, and enriched using the **Google Gemini API** for AI-powered review analysis.

## 📖 Overview

This project simulates a production-style data platform for a food-delivery business (Zomato-style data). Raw data lands in **S3**, gets orchestrated and loaded via **Airflow**, is modeled into clean analytics-ready tables using **dbt** on **Snowflake**, and customer reviews are enriched with sentiment/insight tags generated by the **Gemini API**. On top of the warehouse, a **RAG (Retrieval-Augmented Generation)** layer and a **text-to-SQL** interface let users query the data in natural language — making the final tables ready for BI dashboards, natural-language Q&A, and downstream analytics.

**Pipeline flow (Airflow DAG: `zomato_batch`):**

```
Raw Zomato Data ──▶ AWS S3 (staging)
                         │
                         ▼
                   reload_raw            (SQLExecuteQueryOperator → Snowflake raw layer)
                         │
                         ▼
                  dbt_build_core          (BashOperator → dbt staging/core models)
                         │
                         ▼
                  enrich_reviews          (BashOperator → Gemini API sentiment/insight tags)
                         │
                         ▼
                   dbt_build_ai           (BashOperator → dbt marts on enriched data)
                         │
                         ▼
        Analytics-ready tables ──▶ RAG + Text-to-SQL layer ──▶ Natural-language queries / BI
```

## 🔄 Airflow DAG — `zomato_batch`

The DAG runs four tasks in sequence: raw reload → core dbt models → AI review enrichment → AI-aware dbt models.

| Task            | Operator               | Purpose                                      |
|------------------|-------------------------|-----------------------------------------------|
| `reload_raw`      | SQLExecuteQueryOperator | Load raw Zomato data into Snowflake            |
| `dbt_build_core`  | BashOperator            | Run core/staging dbt models                    |
| `enrich_reviews`  | BashOperator            | Enrich reviews via the Gemini API              |
| `dbt_build_ai`    | BashOperator            | Run dbt models on top of the enriched data     |

## ⚙️ Prerequisites

- Python 3.9+
- Apache Airflow (2.x)
- dbt Core (with the Snowflake adapter — `dbt-snowflake`)
- An AWS account with an S3 bucket for staging
- A Snowflake account/warehouse
- A Google Gemini API key

## 🚀 Setup

1. **Clone the repo**
   ```bash
   git clone https://github.com/chandanas332006-droid/zomato-dataeng.git
   cd zomato-dataeng
   ```

2. **Create a virtual environment & install dependencies**
   ```bash
   python -m venv venv
   source venv/bin/activate      # venv\Scripts\activate on Windows
   pip install -r requirements.txt
   ```

3. **Configure environment variables** — create a `.env` file (kept out of version control) with:
   ```
   AWS_ACCESS_KEY_ID=...
   AWS_SECRET_ACCESS_KEY=...
   AWS_S3_BUCKET=...
   SNOWFLAKE_ACCOUNT=...
   SNOWFLAKE_USER=...
   SNOWFLAKE_PASSWORD=...
   SNOWFLAKE_WAREHOUSE=...
   SNOWFLAKE_DATABASE=...
   SNOWFLAKE_SCHEMA=...
   GEMINI_API_KEY=...
   ```

4. **Start Airflow** and trigger the DAG(s) in `airflow/`.

5. **Run dbt models**
   ```bash
   cd zomato
   dbt deps
   dbt run
   dbt test
   ```

6. **Run AI enrichment** on customer reviews:
   ```bash
   python ai/enrich_reviews.py
   ```

> Adjust commands above to match your actual `requirements.txt` / dbt profile / script names.
